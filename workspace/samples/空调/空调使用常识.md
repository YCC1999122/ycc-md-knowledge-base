# 开关与运行模式

- 制冷：夏季使用，出风口朝上利于冷气下沉
- 制热：冬季使用，出风口朝下利于热气上升
- 除湿：梅雨天使用，温度不宜设过低
- 送风：只循环空气不制冷，配合风扇更省电
- 自动/睡眠：夜间建议睡眠模式，温度自动微调且更静音

# 温度设定建议

- 夏季制冷建议 26-28℃，每调高 1℃ 约省电 6-8%
- 冬季制热建议 18-22℃，过高易干燥且费电
- 室内外温差不宜超过 7-8℃，避免感冒

# 清洁与保养

- 过滤网每 2 周清洗一次：取下清水冲洗阴干即可
- 每年换季前深度清洁蒸发器与风轮（可请专业人员）
- 外机保持周围通风无遮挡，定期清理散热片灰尘
- 长期停用前开送风模式半天吹干内部，防止霉变

# 常见问题

- 不制冷：先查模式/温度设定，再查过滤网是否脏堵，最后考虑缺氟
- 漏水：多为排水管堵塞或内机倾斜，疏通排水管即可
- 异味：过滤网或蒸发器发霉，清洗并通风
- 噪音大：检查是否安装松动、风扇是否有异物
