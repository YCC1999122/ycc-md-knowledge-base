# 系统结构

分体式空调由室内机（蒸发器、贯流风扇、过滤网、显示与接收模块）和室外机（压缩机、冷凝器、轴流风扇、节流装置）组成，内外机通过铜管（气管/液管）和电源信号线连接。

# 制冷循环原理

1. 压缩机将制冷剂压缩为高温高压气体
2. 冷凝器（外机）散热，制冷剂冷凝为中温高压液体
3. 节流装置（毛细管/电子膨胀阀）降压，变为低温低压雾状
4. 蒸发器（内机）吸热蒸发，室内空气被降温除湿
5. 低温低压气体回到压缩机，循环往复；制热时四通阀换向，流程反转

# 主要部件

- 压缩机：系统心脏，变频机可无极调速更省电静音
- 四通阀：切换制冷/制热流向
- 电子膨胀阀：精确调节制冷剂流量
- 温度传感器：室温/管温/外环温，参与控制与保护
