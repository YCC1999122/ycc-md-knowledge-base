# 产品概述

本知识库收录家用分体式空调（壁挂/柜机）的通用资料，供智能体回答用户提问与辅助操控使用。适用品牌型号不限，内容以通用原理与常识为主。

# 主要参数

- 制冷量：1匹约 2500W，1.5匹约 3500W，2匹约 5000W，3匹约 7200W
- 适用面积：1匹 10-15㎡，1.5匹 15-22㎡，2匹 22-32㎡，3匹 32-45㎡
- 额定电压：220V/50Hz（柜机大功率机型可能为 380V）
- 能效等级：一级最省电，APF 越高越好
- 制冷剂：常见 R32、R410A

# 安全注意事项

- 长时间不用请拔掉电源或关闭空气开关
- 禁止用湿手操作遥控器或触碰电源插头
- 制冷剂泄漏时远离火源并开窗通风，联系售后
- 外机安装需牢固，定期检查支架锈蚀情况
