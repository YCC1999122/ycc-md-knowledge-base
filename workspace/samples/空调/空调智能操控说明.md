# 操控指令速查

- 开关机："打开空调" / "关闭空调"
- 调温："温度调到 26 度" / "调高一度" / "调低两度"
- 模式："切换到制冷/制热/除湿/送风/睡眠模式"
- 风速："风速调为自动/低风/中风/高风"
- 扫风："开启上下扫风" / "关闭左右扫风"
- 定时："两小时后关机" / "明早 7 点开机"

# 与智能体对话示例

- 用户："现在屋里多少度？有点热" → 查询室温传感器后建议并执行制冷 26℃
- 用户："空调开一晚上会费多少电？" → 按匹数与能效估算并给出睡眠模式建议
- 用户："空调好像不制冷" → 按常见问题排查树逐步引导（模式→滤网→缺氟）

# 联动场景

- 回家模式：门锁开启 → 提前 10 分钟开空调制冷 26℃
- 睡眠模式：23:00 → 自动切换睡眠模式并关闭屏显
- 节能联动：室内无人超 30 分钟 → 自动关机或升至 28℃
- 湿度联动：湿度 > 70% → 自动开启除湿
